# Imagegen design

Every mode here needs an image-generation tool. When a task fits, offer the matching mode to Bea in one line and use it only on her yes. Without an image tool, say so and stop. Pick one mode, read only its reference file.

| Mode | When | Read |
|---|---|---|
| brandkit | Brand guidelines board, logo system, identity deck | `references/brandkit.md` |
| image-to-code | Generate website design images first, then implement them in code | `references/image-to-code.md` |
| web | Design reference images for a website, one image per section (no code) | `references/imagegen-frontend-web.md` |
| mobile | Mobile app screen concepts and flows in phone mockups (no code) | `references/imagegen-frontend-mobile.md` |
