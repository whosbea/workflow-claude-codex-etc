# Formato iceberg

## Progressão das camadas

As camadas devem aumentar em:

- obscuridade;
- complexidade;
- gravidade;
- estranheza;
- dificuldade de verificação;
- impacto.

## Para cada item

Inclua:

- nome;
- resumo;
- camada;
- justificativa;
- evidência;
- grau de certeza;
- conexão com o próximo;
- potencial visual;
- cuidado ético;
- tempo sugerido.

## Regras

- não use itens apenas para preencher;
- diferencie rumor e fato;
- marque alegações não confirmadas;
- remova itens sem base mínima;
- crie conexão narrativa entre as camadas.
