# Pipeline de vídeo master

## Entrada

Pode receber:

- ideia bruta;
- anotações;
- arquivos;
- links;
- transcrições;
- pesquisas;
- referências;
- duração desejada;
- formato desejado.

## Processo

1. Use `ideia-para-conceito`.
2. Use `pesquisa-roteiro` quando houver fatos externos.
3. Use `titulos-thumbnails`.
4. Escolha a estrutura adequada:
   - `storytelling-educativo`;
   - `formato-iceberg`;
   - `formato-experimento`;
   - outro formato coerente.
5. Use `hook-primeiros-30s`.
6. Use `roteiro-completo`.
7. Use `auditoria-retencao`.
8. Use `direcao-edicao`.
9. Use `qa-factual-editorial`.
10. Use `pacote-publicacao`.

## Estrutura de saída

Crie:

- `00-brief.md`
- `01-conceito.md`
- `02-pesquisa.md`
- `03-fontes.md`
- `04-titulos-thumbnails.md`
- `05-outline.md`
- `06-roteiro.md`
- `07-edicao.md`
- `08-qa.md`
- `09-publicacao.md`

## Aprovação

O vídeo só está pronto quando:

- a promessa está clara;
- o hook confirma a promessa;
- os fatos principais têm fonte;
- o roteiro possui progressão;
- o payoff foi entregue;
- título e thumbnail representam o conteúdo;
- não existem bloqueadores de QA.
