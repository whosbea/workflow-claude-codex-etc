# Project Planning

Use esta skill para planejar projetos e features.

## 1. Contexto
Identifique:
- Objetivo.
- Problema.
- Público.
- Restrições.
- Stack existente.
- Prazo, se houver.

## 2. Escopo
Separe:
- Essencial.
- Importante.
- Opcional.
- Fora de escopo.

## 3. Fases
Organize em:
- Setup.
- Base estrutural.
- Funcionalidades principais.
- Validações.
- Testes.
- Documentação.
- Revisão final.

## 4. Tarefas
Cada tarefa deve ter:
- Descrição.
- Critério de aceite.
- Dependências.
- Risco.
- Ordem de execução.

## 5. Riscos
Avalie:
- Técnico.
- Produto.
- Segurança.
- Prazo.
- Manutenção.

## Saída esperada
Responda com:
1. Resumo do plano.
2. Fases.
3. To-do list ordenada.
4. Critérios de aceite.
5. Riscos e mitigação.
