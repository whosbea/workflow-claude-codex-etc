# Project Planning

Use this skill to plan projects and features.

## 1. Context
Identify:
- Goal.
- Problem.
- Audience.
- Constraints.
- Existing stack.
- Deadline, if any.

## 2. Scope
Separate into:
- Essential.
- Important.
- Optional.
- Out of scope.

## 3. Phases
Organize into:
- Setup.
- Structural foundation.
- Core features.
- Validations.
- Tests.
- Documentation.
- Final review.

## 4. Tasks
Each task must have:
- Description.
- Acceptance criterion.
- Dependencies.
- Risk.
- Execution order.

## 5. Risks
Assess:
- Technical.
- Product.
- Security.
- Schedule.
- Maintenance.

## Expected output
Respond with:
1. Plan summary.
2. Phases.
3. Ordered to-do list.
4. Acceptance criteria.
5. Risks and mitigation.
