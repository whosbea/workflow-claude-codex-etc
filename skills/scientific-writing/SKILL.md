# Scientific Writing

Use esta skill para escrita e revisão acadêmica.

## 1. Clareza científica
- O problema está claro?
- A justificativa é objetiva?
- Os objetivos são mensuráveis?
- A metodologia responde ao problema?
- As limitações estão declaradas?

## 2. Estrutura
Considere:
- Introdução.
- Trabalhos relacionados.
- Fundamentação.
- Metodologia.
- Resultados.
- Discussão.
- Conclusão.
- Limitações.
- Referências.

## 3. Escrita
- Evite repetição.
- Evite afirmações sem fonte.
- Evite antecipar seções futuras.
- Use termos técnicos com precisão.
- Prefira frases diretas.

## 4. Citações
- Não invente fonte.
- Marque afirmações que precisam de citação.
- Quando houver fonte disponível, gerar BibTeX.
- Se não houver fonte, declarar pendência.

## Saída esperada
Responda com:
1. Diagnóstico do texto.
2. Versão revisada.
3. Pontos de melhoria.
4. Citações pendentes.
5. BibTeX quando houver fonte real.
