# Auditoria de retenção

## Avaliação por bloco

Dê nota de 0 a 5 para:

- novidade;
- clareza;
- tensão;
- recompensa;
- função narrativa;
- força visual.

Trechos com média abaixo de 3 precisam ser:

- cortados;
- condensados;
- movidos;
- reescritos.

## Procure

- introdução lenta;
- contexto antes da curiosidade;
- repetição;
- promessas esquecidas;
- exemplos sem consequência;
- listas longas;
- transições fracas;
- jargão;
- excesso de estímulo;
- falta de variação;
- clímax fraco;
- conclusão sem payoff.

## Entrega

- diagnóstico;
- pontos de abandono;
- loops abertos;
- payoffs;
- cortes;
- alterações;
- versão revisada.
