# Design presets

Pick one mode per task, read only its reference file, and follow it within its scope. For the general landing/portfolio direction use `design-taste-frontend`; these modes replace it when they apply.

Modes marked "Ask Bea first": when the task fits, offer them in one line and use only on her yes.

| Mode | When | Read |
|---|---|---|
| minimalist | Bea asks for minimalist, clean, editorial, warm monochrome | `references/minimalist-ui.md` |
| brutalist | Bea asks for brutalist, Swiss, terminal, declassified look | `references/industrial-brutalist-ui.md` |
| premium | Bea asks for a premium, expensive, high-end agency look | `references/high-end-visual-design.md` |
| redesign | Upgrade an existing site or app without breaking it (audit first) | `references/redesign-existing-projects.md` |
| gpt-taste | Ask Bea first (imposes GSAP, AIDA structure) | `references/gpt-taste.md` |
| stitch | Ask Bea first (Google Stitch DESIGN.md) | `references/stitch-design-taste.md`, example `references/stitch-DESIGN.md` |
| bento | Ask Bea first (Motion-Engine Bento, Framer Motion) | `references/motion-engine-bento.md` |
