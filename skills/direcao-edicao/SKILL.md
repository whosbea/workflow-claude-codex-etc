# Direção de edição

## Funções visuais

Cada elemento deve cumprir uma função:

- provar;
- explicar;
- contextualizar;
- comparar;
- emocionar;
- aliviar;
- orientar;
- criar antecipação.

## Entrega

- shot list;
- B-roll;
- capturas de tela;
- diagramas;
- animações;
- texto na tela;
- música;
- efeitos sonoros;
- pausas;
- pontos de corte;
- assets;
- materiais de terceiros;
- licenças necessárias.

Não adicione efeitos sem função.
