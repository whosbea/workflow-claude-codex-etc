# Test Plan Generator

Use esta skill para transformar uma feature em plano de testes.

## 1. Entendimento
Identifique:
- O comportamento esperado.
- A regra de negócio.
- Entradas válidas.
- Entradas inválidas.
- Permissões envolvidas.
- Dependências externas.

## 2. Cenários
Cubra:
- Caminho feliz.
- Validação.
- Recurso inexistente.
- Usuário sem permissão.
- Estado vazio.
- Erro externo.
- Regressões prováveis.

## 3. Tipos de teste
Sugira:
- Unitários.
- Integração.
- E2E.
- Contrato.
- Regressão.

## 4. Qualidade
Cada teste deve ter:
- Nome claro.
- Arrange, Act, Assert.
- Dado de entrada.
- Resultado esperado.
- Motivo de existir.

## Saída esperada
Responda com:
1. Plano geral.
2. Tabela de cenários.
3. Testes prioritários.
4. Casos de borda.
5. Sugestão de implementação.
