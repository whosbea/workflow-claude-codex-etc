# Storytelling educativo

## Estrutura

1. problema observável;
2. pergunta;
3. hipótese;
4. modelo simples;
5. tentativa;
6. falha ou limite;
7. conceito técnico;
8. aplicação;
9. consequência;
10. síntese.

## Regras

- introduza um termo técnico quando ele se tornar necessário;
- use exemplos concretos;
- use analogias;
- explique onde a analogia deixa de funcionar;
- apresente um conceito por vez;
- faça perguntas antes das respostas;
- construa do concreto para o abstrato.
