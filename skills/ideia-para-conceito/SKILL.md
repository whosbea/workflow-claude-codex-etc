# Ideia para conceito

## Saída obrigatória

1. ideia original;
2. pergunta central;
3. público;
4. conhecimento prévio esperado;
5. curiosidade ou problema;
6. promessa principal;
7. transformação do espectador;
8. conflito;
9. diferencial;
10. prova visual;
11. formato recomendado;
12. duração estimada;
13. riscos;
14. três versões do conceito.

## Fórmula

> Este é um vídeo sobre [tema], contado por [mecanismo narrativo], no qual [conflito], para que o público [transformação].

Não avance para o roteiro enquanto o conceito estiver genérico.
