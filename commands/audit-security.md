Faça uma auditoria de segurança defensiva no projeto ou trecho indicado.

Use:
- security-reviewer
- secure-coding-checklist

Analise:
1. Autenticação.
2. Autorização.
3. Controle de acesso.
4. Validação de entrada.
5. Dados sensíveis.
6. Logs.
7. Secrets.
8. Configurações.
9. Dependências.
10. Uploads.
11. Banco de dados.
12. Exposição de informações.
13. Riscos OWASP e LGPD básica.

Entregue:
- Achados por severidade.
- Evidências.
- Impacto.
- Correção recomendada.
- Prioridade.

Não execute testes ofensivos.
Não rode comandos destrutivos.
Não altere código sem pedido explícito.

Argumentos do usuário:
$ARGUMENTS
